**Course:** CMPS 310

### 1. Sprint 2 Overview

Sprint 2 focused on completing the system design documentation, reviewing consistency between project models, integrating the final diagrams into the report, and preparing repository evidence for Milestone 1.

### 2. Sprint Review

The following project deliverables were included in the Sprint 2 review:

- Inventory Management System design class diagram.
- Use Case Diagram and supporting specifications.
- Data Flow Diagrams: Level 0, Level 1, and Level 2.
- Model consistency and traceability documentation (B12).
- Report and Visual Paradigm integration (B13).
- Repository evidence and diagram screenshots (B14).

The project repository contains the Milestone 1 Word report, the native Visual Paradigm project, supporting documentation, and diagram evidence.

### 3. Deliverable Verification

The team reviewed the availability and organization of the Sprint 2 deliverables. The five diagram screenshots were uploaded under `Milestone-1/scrum/evidence/`.

Related GitHub tasks and their supporting documentation provide traceability between the design work and the submitted artifacts.

### 4. Challenges and Lessons Learned

The project highlighted the importance of maintaining consistency across the DFD levels, use cases, class design, Word report, and Visual Paradigm project.

Keeping related documentation and evidence together in the repository helps reduce confusion during integration and final verification.

### 5. Retrospective Improvements

The following improvements were identified for future project work:

- Use a shared model-consistency checklist before finalizing diagrams.
- Review changes to the Visual Paradigm project against the Word report.
- Maintain clear links between GitHub issues, supporting files, and evidence.
- Verify final deliverables before closing release-related tasks.

### 6. Follow-up Actions

The remaining release activity is tracked through **B16 – Verify Final Release Files and Submission Links**.

Final verification should include the report, Visual Paradigm project, repository links, and submission requirements.
